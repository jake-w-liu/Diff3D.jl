Differentiable Rendering

Soft rasterization, losses, reverse-mode AD and inverse-rendering optimizers.

Diff3D.SoftRasterizerConfig — Type
SoftRasterizerConfig(; sigma=1.0, gamma=1.0, bg_color=Color3(0.0, 0.0, 0.0), eps=1e-8)

Configuration for soft_render. sigma is the edge softness in pixels (coverage sigmoid_approx(d / sigma) of the signed distance d), gamma the depth-softmax temperature in NDC depth units, and bg_color the colour of the virtual background surface at the far plane. eps (positive) is the floor added to the background weight, the relative near/far clipping margin, and the doubled screen area (in pixel²) below which a triangle's coverage fades smoothly to zero as it degenerates.

Diff3D.SoftRenderWorkspace — Type

Reusable scratch/output buffers for repeated soft_render calls with element type T.

When passed as workspace, the returned image array is owned by the workspace and is overwritten by the next render that reuses the same dimensions.

Diff3D.differentiable_render — Method
differentiable_render(params, setup_fn, width, height;
                      sigma=1.0, gamma=1.0, workspace=nothing)

Render an image from explicit parameters. setup_fn(params) returns (vertices, faces, face_colors, view_proj, bg_color). Preserve the parameter scalar type in these values when differentiating with ForwardDiff or ADVar; converting a differentiated value to Float64 discards its derivative.

This function delegates to soft_render. workspace follows the SoftRenderWorkspace ownership and scalar-type rules. The function does not mutate a scene or camera on the caller's behalf.

Diff3D.point_line_distance — Method
point_line_distance(px, py, ax, ay, bx, by)

Unsigned distance from point (px, py) to the infinite line through (ax, ay) and (bx, by). The line length is floored at 1e-20, so coincident endpoints give distance zero instead of dividing by zero. Float64 inputs use a rescaled evaluation that stays finite for coordinates near floatmax.

source
Diff3D.point_segment_distance — Method
point_segment_distance(px, py, ax, ay, bx, by)

Distance from point (px, py) to the closed segment (ax, ay)-(bx, by), smoothed as sqrt(d^2 + 1e-12) so the derivative stays finite (zero) when the point lies on the segment. The projection parameter is clamped to [0, 1]; a segment shorter than 1e-10 is treated as its first endpoint.

source
Diff3D.sigmoid_approx — Method
sigmoid_approx(x)

The logistic function 1 / (1 + exp(-x)), evaluated in the form that cannot overflow for either sign of x. It is exact (not an approximation) and preserves the scalar type, so ForwardDiff and ADVar inputs differentiate it.

source
Diff3D.signed_distance_to_triangle — Method
signed_distance_to_triangle(px, py, ax, ay, bx, by, cx, cy)

Signed screen-space distance from point (px, py) to the triangle with vertices (ax, ay), (bx, by), (cx, cy) in either winding: inside (or on the boundary) it is the distance to the nearest edge line (point_line_distance); outside it is minus the distance to the nearest edge segment (point_segment_distance). A triangle whose doubled area is below 1e-20 returns -1e10. This is the coverage argument of soft_render, which evaluates sigmoid_approx(d / sigma).

Diff3D.soft_render — Method

Differentiable soft rendering. Takes explicit arrays rather than scene-graph objects for AD compatibility.

Arguments:

  • vertices: Vector{Vec3{T}} — world-space vertex positions
  • faces: Vector{NTuple{3,Int}} — triangle face indices (1-based)
  • face_colors: Vector{Color3{T}} — one color per face
  • view_proj: Mat4{T} — combined view-projection matrix
  • width, height: image dimensions
  • config: SoftRasterizerConfig

Returns: Array{T, 3} of size (height, width, 3) — RGB image.

Degenerate triangles: a triangle whose doubled screen area |A| is below config.eps (pixel²) has its coverage multiplied by s(|A| / eps) with s(t) = t^2 (3 - 2t), so a collapsing triangle fades out continuously and a zero-area triangle covers nothing; triangles with |A| >= eps are unaffected.

Threading: when Julia runs with several threads, images of at least 4096 pixels with an isbits scalar type (Float32, Float64, ForwardDiff duals) are rendered in parallel column blocks; the reverse-mode (ADVar) pixel stage does the same before recording. Each pixel performs the same operations as in a serial render, so images and derivatives are bit-identical for any thread count. The parallel path allocates its task objects (a few kilobytes per call, also with a workspace); a single-threaded session keeps the allocation-free reuse. A workspace must not be shared by concurrent calls.

Diff3D.soft_render_scene — Method
soft_render_scene(scene, camera, width, height;
                  sigma=1.0, gamma=1.0, workspace=nothing)

Render visible triangle meshes, posed skins, and triangle instances with soft coverage. Honors camera layers, LOD selection, and geometry draw ranges. Scene extraction uses Float64 geometry and colors. For derivatives with respect to geometry or cameras, use soft_render or differentiable_render with explicit parametric inputs.

Pass a SoftRenderSceneWorkspace to reuse scene-extraction and render buffers. Its returned image is overwritten by the next render that reuses the same workspace and dimensions; copy the image to retain it.

Diff3D.loss_l1 — Method
loss_l1(image, target)

Mean absolute error sum(abs(image - target)) / length(image) between two (H, W, C) image arrays of equal size, with the accumulation and result type of loss_mse.

source
Diff3D.loss_mse — Method
loss_mse(image, target)

Mean squared error sum((image - target)^2) / length(image) between two (H, W, C) image arrays of equal size, accumulated with compensated summation. The result type is promote_type(Float32, float(promote_type(T, S))); Float16 and Float32 data are accumulated in Float64.

source
Diff3D.loss_silhouette_iou — Method
loss_silhouette_iou(image, target; threshold=0.05)

Soft silhouette intersection-over-union loss 1 - IoU. Each pixel's occupancy is a steep sigmoid (slope 200) of its brightest channel minus threshold, rescaled so a black pixel has occupancy 0; the intersection and union sum the per-pixel minimum and maximum occupancies. A 1e-8 smoothing term makes two empty silhouettes give loss 0. threshold must lie in [0, 1].

source
Diff3D.loss_ssim — Method
loss_ssim(image, target; window_size=7, C1=0.01^2, C2=0.03^2)

Structural-similarity loss 1 - mean(SSIM), so minimizing it maximizes SSIM. SSIM is evaluated per channel on every fully contained window_size x window_size uniform window (no padding), using window means, unbiased (n - 1) variances and covariance, and the stabilizing constants C1, C2; the mean runs over all windows of all channels. window_size must be an odd integer >= 3 no larger than either image dimension.

With several Julia threads, at least 1024 windows and an isbits accumulator (Float32, Float64, ForwardDiff duals), windows are evaluated in parallel and summed in the serial order, so the result does not depend on the thread count; that path allocates one buffer of window values.

Adam optimizer for inverse rendering. Better convergence than vanilla gradient descent. Accepts the same ad gradient-backend keyword as inverse_render_optimize.

Diff3D.inverse_render_optimize — Method

Gradient descent optimizer for inverse rendering. Optimizes params to minimize the loss between rendered image and target.

Arguments:

  • initial_params: starting parameter vector
  • target_image: goal image (H×W×3 array)
  • render_fn: params -> image (must be ForwardDiff-compatible)
  • loss_fn: (rendered, target) -> scalar loss
  • lr: learning rate
  • n_iters: number of optimization steps
  • verbose: print progress
  • ad: :auto, :forward, or :reverse gradient backend. :auto uses the single-pass reverse engine for wider parameter vectors and falls back to ForwardDiff when the reverse engine reports an unsupported objective.

Returns: (optimizedparams, losshistory)

Diff3D.numerical_gradient — Method

Compute numerical (finite difference) gradients for validation.

Uses second-order accurate central differences (O(δ²) error) so that this serves as a trustworthy oracle for the automatic-differentiation gradients.

Diff3D.ADVar — Type
ADVar

Reverse-mode automatic-differentiation scalar used by reverse_gradient and reverse_value_gradient. Its primal value and adjoint are Float64. Arithmetic, comparisons, and the elementary functions of Base (including the trigonometric, hyperbolic, exponential, logarithmic, power, rounding, fma, hypot, min/max, mod/rem and rem2pi families) are recorded on a task-local tape while a gradient pass is active; other Real types promote to ADVar. At nonsmooth points the recorded derivative is a selected branch derivative (for example, min/max ties select the first argument), which can differ from ForwardDiff's choice there.
